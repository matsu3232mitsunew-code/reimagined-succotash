# reimagined-succotash

ブラウザで遊べる **ローマ字タイピングゲーム** です。60秒でどれだけ打てるかに挑戦します。

## 遊び方

`index.html` をブラウザで開き、`Space` キーでスタート。表示された言葉をローマ字で入力します。
ビルドやサーバーは不要です。

- `shi` / `si`、`tsu` / `tu`、`kyo` / `kixyo` など、**どの打ち方でも正解**になります
- 「ん」は子音の前なら `n` 一打ちでもOK（母音・な行・や行の前や語末は `nn`）
- 「っ」は `kitte` のような重ね打ちでも `kixtute` のような単独入力でもOK
- コンボが続くほど1打あたりの得点がアップ。単語を打ち切るとボーナス
- ベストスコアはブラウザに保存されます
- スマホでは画面タップでキーボードが開きます

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `romaji.js` | かな → ローマ字の入力判定エンジン |
| `words.js` | お題の単語リスト（追加・変更はここ） |
| `game.js` | ゲームの進行・画面・効果音 |
| `index.html` / `style.css` | 画面（ダークモード対応） |
